### 🚀 Flagowy Projekt (Featured): NexusERP – Warehouse & Order Management System
Kompletny system zarządzania magazynem i zamówieniami B2B, inspirowany rozwiązaniami klasy ERP:
* **Backend:** REST API w ASP.NET Core 8, Clean Architecture, Entity Framework Core, PostgreSQL, autoryzacja JWT z rolami.
* **Frontend:** React + TypeScript, Tailwind CSS, shadcn/ui, TanStack Table & Query.
* **Jakość i DevOps:** Testy jednostkowe xUnit, pipeline CI w GitHub Actions, pełna konteneryzacja za pomocą `docker-compose`.
